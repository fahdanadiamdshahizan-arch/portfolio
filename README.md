# Fahda Nadia — Portfolio

Responsive portfolio website built with HTML, CSS and JavaScript. No build tools required.

## Run in VS Code
1. Extract the ZIP.
2. Open the `fahda-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** VS Code extension and choose **Open with Live Server**.

## Customize
- Edit text and projects in `index.html`.
- Edit colors and layout in `style.css` (CSS variables at the top).
- Edit interactions in `script.js`.
- Add your own approved images in `assets/` and reference them from HTML.
- Add a PDF resume under `assets/` and add a link to it if desired.

## Publish via GitHub Pages
Create a public GitHub repository, upload the files from this folder to its root, then go to Settings > Pages > Deploy from a branch > main / root. Do not publish confidential client material.

Note: Google Fonts require internet; the site falls back to Arial if offline.
